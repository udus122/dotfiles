# clear-japanese

AI が書いた日本語がおかしく読めるのは、事柄を正しく説明していないからである。対比・比喩・短い文で印象を作り、誰が何をどうするのかを書いていない。書いた本人は文脈を知っているので読めてしまうが、後から文書だけを渡された人は意味を組み立てられない。

このスキルでは、一文ごとに「これはどういう意味？」と自分に聞き、その答えを本文に書く。言い回しを一覧と照らし合わせるより先に、意味が書かれているかを確かめる。

## 書き方

1. 主文を先に書く。言いたいことを最初の文に書く。「〜ではなく」「〜しなくていい」「〜だけで」のような対比・否定・留保から書き出さない。打ち消しの部分を外しても意味が通るなら、打ち消しは消す。
2. 字義どおりの動詞で書く。「倒す」「壊れる」「効く」「添える」「支える」「引き受ける」「担保する」は、実際に何をするのかを表す動詞に置き換える。主体・対象・条件を省かない。「片方」「〜側」「これ」は、指すものの名前で書く。
3. 印象で押さない。短い文を並べる、対句にする、体言止めにする、目的語の後に読点を打って強調する、といった書き方をしない。2つの文をつないだときに主体や条件が出てくるなら、つないだ1文で書く。
4. 宣伝の言い回しを使わない（「〜するだけ」「最も手軽」「一番の近道」「醍醐味」）。良さは、読み手が何をできるようになるかで書く。
5. 読み手が知っている言葉で書く。利用者向けの文に中の仕組みの名前を出さず、操作と結果で書く（「○○を押すと△△が開きます」）。

## 書いたあとの見直し

書き終えたら、頭から一文ずつ読み、次のやりとりを自分で行う。

- 「これはどういう意味？」と聞く
- 答えを、読み手が知っている言葉で一文にする
- 答えと本文が違えば、答えを本文にする

答えられない文は、書き手が何を言いたいかを決めていない文である。推測で埋めず、ユーザーに聞く。既存の文書を直すときは、元の文書にない事実・数値・判断を足さない。

## 例

| 元の文 | どういう意味？ | 直した文 |
|---|---|---|
| 迷ったら、載せない側に倒します。 | 載せるかどうか判断できない項目は、載せない | 載せるかどうか判断できない項目は、一覧に載せません。 |
| 速さを取ると、正しさが崩れる。 | 集計を短い間隔で回すと、確定前の売上が数字に入る | 集計を1分ごとに実行すると、確定前の売上が合計に含まれます。 |
| 設定はいらない。つなぐだけ。 | URL を貼れば、設定画面を開かずにデータを読める | 接続先の URL を貼り付けると、設定を変えずにデータを読み込めます。 |
| データを、カタログが束ねる。 | カタログの一覧から、各データの場所と列の説明を引ける | カタログには、各データの保存場所と列の説明が載っています。 |

例の直した文に入っている「1分ごと」「設定画面」などの具体的な中身は、例のために置いたものである。実際の文書では、本文や素材から分かる事実だけを使い、分からない部分はユーザーに聞く。
